# Medal GLB models

Unique 3D medals live under course folders:

- `sites/medal-M0.glb` … `sites/medal-M9.glb`
- `agents/medal-M0.glb` … `agents/medal-M6.glb`

Regenerate procedural set:

```bash
node scripts/build-medal-glbs.mjs
```

Drop your own “crazy” models with the same filenames to replace them. Prefer ~100KB–2MB, origin-centered, ~1 unit wide.
