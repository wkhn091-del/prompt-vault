ים חי, בתוך האתר שלך

גלים שמחושבים בזמן אמת, ארבעה מצבי אור, וצלילה שנשלטת בגלילה. קובץ JS אחד, בלי ספריות ובלי תמונות.

לקוד

גללו כדי לצלול

קו המים

המצלמה בדיוק בגובה פני הים: חצי שמים, חצי מים. כל גל שעובר מזיז את הקו.

קרני אור

חמישה מטרים מתחת. השמש נשברת בגלים ויורדת בקרניים, ואת השמים רואים רק דרך חלון עגול מעל הראש.

הכחול

ארבעים מטרים. האדום והכתום כבר נבלעו במים. נשאר כחול, וחלקיקים שמרחפים לאט.

החושך

מאתיים מטרים. כמעט אין אור, רק נקודות קטנות שזוהרות.

וסערה למעלה

עולים בחזרה, ומזג האוויר התחלף: גלים של שלושה מטרים, גשם וברקים. כל תחנה קובעת גובה, זווית ומצב אור משלה.

גובה 3.2מ׳

איך מכניסים את הים לאתר

קובץ אחד, ocean.js, בלי ספריות ובלי תמונות. הים מצויר בכרטיס המסך (WebGL), וכל תוכן שתשימו בתוך הסקשן מוצג מעליו.

35 KB, בלי תלויות

  1. מוסיפים את הקובץ

    שומרים את ocean.js בתיקיית האתר ומוסיפים אותו לפני סוף ה־body. הוא מוצא לבד כל section עם המחלקה fx-ocean.

    <script src="ocean.js"></script>

  2. צלילה בגלילה

    כל div עם fx-ocean__stop הוא תחנה. data-level הוא גובה המצלמה במטרים: חיובי מעל המים, שלילי מתחת. בין התחנות המצלמה זזה לבד, לפי הגלילה.

    <section class="fx-ocean" data-mood="sunset">
  <div class="fx-ocean__stop" data-level="3">
    <h2>מעל המים</h2>
  </div>
  <div class="fx-ocean__stop" data-level="0">
    <h2>על קו המים</h2>
  </div>
  <div class="fx-ocean__stop" data-level="-6" data-pitch="25">
    <h2>מתחת למים</h2>
  </div>
  <div class="fx-ocean__stop" data-level="-60">
    <h2>בעומק</h2>
  </div>
  <div class="fx-ocean__stop" data-level="6" data-mood="storm">

</section>

אפשרויות

מאפייןאיפהמה הוא עושה
data-moodsection או תחנהday, sunset, night, storm. בתחנה: מחליף את מצב האור כשמגיעים אליה. ברירת מחדל: שקיעה.
data-levelתחנה, או section בלי תחנותגובה המצלמה במטרים. חיובי מעל המים, שלילי מתחת. ברירת מחדל: 3.2.
data-pitchתחנההטיית המבט במעלות, חיובי למעלה. בלי ערך: קצת למטה מעל המים, ולמעלה אל האור מתחת למים.
data-turnתחנהסיבוב המבט לצדדים, במעלות.
data-fovתחנהזווית הראייה במעלות. בלי ערך: לפי צורת המסך.
data-wavessectionגובה הגלים, כפול. 0.5 ים שקט, 2 ים גבוה.
data-speedsectionמהירות תנועת הגלים. ברירת מחדל: 1.
data-driftsectionכמה מהר המצלמה שטה קדימה, במטרים לשנייה. 0 עוצר. ברירת מחדל: 0.6.
data-qualitysectionhigh, mid או low. בלי ערך: לפי המכשיר, ויורד לבד אם המכשיר מתקשה.
data-lightningsectionoff מבטל את הברקים בסערה.
--fx-ocean-heightCSSגובה הים כשאין תחנות. ברירת מחדל: 100vh.
--fx-ocean-levelCSS, לקריאההגובה הנוכחי במטרים, לשימוש בעיצוב שלכם.

שליטה מקוד

const sea = document.querySelector('.fx-ocean').fxOcean;

sea.setMood('night');      // day, sunset, night, storm
sea.go(2);                 // גלילה לתחנה השלישית
sea.go({ level: -12 });    // מעבר לעומק 12 מטר, בלי גלילה
sea.go(null);              // חזרה לשליטת הגלילה
sea.setQuality('mid');     // high, mid, low

document.querySelector('.fx-ocean').addEventListener('fx:ocean-level', (e) => {
  console.log(e.detail.level, e.detail.under);   // הגובה במטרים, והאם מתחת למים
});

חשוב לדעת

  • הים מצויר ברזולוציה מוקטנת, נעצר כשהוא לא על המסך, ויורד באיכות לבד במכשיר חלש.
  • בלי WebGL מוצג רקע מצויר של שמים וים, והתוכן נשאר קריא.
  • אם במכשיר מוגדרת הפחתת תנועה: הים עומד, המעבר בין תחנות הוא חיתוך מהיר, ואין ברקים, גשם ובועות.
  • בסערה יש לכל היותר שני הבזקים קצרים כל חמש שניות. data-lightning="off" מבטל אותם.
  • אפשר לשים בתוך התחנות כל דבר: כפתורים, טפסים, תמונות. הים נשאר מאחור.
